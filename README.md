# ARMORED

- Created by Ondřej Micka

A simple two-player tank game built in Java where players control tanks, shoot bullets and rockets, and battle on various maps.

## Features

- **Two-player gameplay** - Play against another player on the same keyboard
- **Multiple maps** - Choose from different maps with unique layouts and obstacles
- **Customizable controls** - Configure key bindings for each player
- **Collision detection** - Realistic tank and bullet interactions
- **Bullet types** - Basic bullets and guided rockets
- **Health system** - Track and display player health

## Technologies Used

- **Java** - Core language
- **Swing** - GUI framework for the user interface
- **Gson** - JSON serialization for settings management
- **IntelliJ IDEA** - Development environment
- **Gemini AI** - Code generation assistance
- **GitHub Copilot** - Code generation assistance
- **GitHub** - Version control
- **Tiled** - Map editor for creating game maps

## Running the Game

1. Compile the project with Java
2. Run the `Main` class
3. Configure settings from the menu
4. Select a map and start playing

## Controls

Controls are fully customizable in the settings menu. Default settings are stored in `res/settings.json`.
